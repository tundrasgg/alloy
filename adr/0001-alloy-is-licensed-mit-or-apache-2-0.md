# ADR 0001: Alloy is licensed MIT OR Apache-2.0

- Status: accepted
- Subject: project
- Specs: none

## Context

The project is open source first and should be usable inside any other software.

## Decision

All code and documents are dual licensed MIT OR Apache-2.0. Contributions are accepted under the same terms.

## Consequences

- Dependencies must be compatible with both licenses, see ADR 0035.
- Both license texts live at the repository root.

## Alternatives rejected

- Copyleft licenses: they limit who can embed and extend Alloy.
