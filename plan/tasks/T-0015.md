## Goal

ADR 0037 records the pilot's answer to a pivotal question: where the source is hosted and where CI runs. `adr/README.md` indexes it.

## Scope

- Write `adr/0037-<slug>.md` from `agent/templates/adr.md`, status `accepted`, at most 40 lines.
- Decision to record: the canonical repository is the public GitHub repository `tundrasgg/alloy`, default branch `main`; CI is GitHub Actions on GitHub-hosted runners; CI runs exactly `cargo xtask ci` and nothing else gates a merge.
- Add the ADR to the index in `adr/README.md` under a fitting subject.

## Out of scope

- Workflow files or any other CI configuration (T-0016).
- Release, registry, or publishing policy.

## Acceptance

```
test -f adr/0037-*.md && echo ok              # expected: ok
test $(wc -l < adr/0037-*.md) -le 40 && echo ok  # expected: ok
```

## Notes

The pilot chose a public repository and GitHub-hosted runners in the lead session that cut this task, after first choosing and then rejecting Blacksmith runners; plan/decisions.md D-0004 is the provisional record. Alternatives a reasonable engineer would weigh: third-party hosted runners such as Blacksmith (faster, but another vendor account; rejected by the pilot), self-hosted runners (operational burden, unsafe for a public repository taking fork pull requests). GitHub-hosted runners are free for public repositories.
