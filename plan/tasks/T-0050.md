## Goal

ARFC 0005 specifies the public interface of `alloy-sim` that scenarios and tests use, so T-0009 (build) and T-0010 (verify) can work in parallel against it.

## Scope

- The world: creating hosts, giving each its `mem` runtime, links and their properties (latency, loss, reordering, duplication, bandwidth, MTU), and how hosts address each other.
- The fault injection API for every fault in section 3.3 (crash at an await point, restart, partition, clock skew, disk faults), and when each may be scheduled.
- The scenario runner: seed input, virtual time budget, stop conditions, the end-of-run summary already in clauses 3.2.4 to 3.2.6, and the trace file option.
- The hook points the checkers in section 3.6 attach to, without specifying the checkers themselves.
- Enough to write M0 exit criteria 1 and 2 as tests: a 100-host echo scenario, two runs with one seed, and one virtual hour under 60 seconds.
- ADR 0054 if a choice constrains later design.

## Out of scope

- The NAT models (T-0011) and the checkers' algorithms.
- Changes to the `alloy-rt` and `alloy-seam` interfaces from T-0006, unless a gap blocks this task; then report it as a `spec-issue`.
