## Goal

The `alloy` CLI runs M11 rung 2 as ARFC 0002 section 3.15 states: `alloy init`, `alloy join`, `alloy login <code>`, `alloy login --issue-code`, and `alloy node list`. This is part 4 of T-0136, built in parallel with its part 3 (D-0069).

## Scope

- Branch `task/T-0141` from `task/T-0136`. Merge `task/T-0136` again whenever it moves, and before you report.
- T-0112's Scope, rescoped to the profile:
  - `init` calls `alloyd::init::init`, then enables and starts the service;
  - `join` calls `alloyd::join::join` once T-0136 pushes it. Until then, build against its documented signature and leave `join`'s end-to-end test for last;
  - `login` and `login --issue-code` use the API port and the local admin socket;
  - `node list` (alias `node ls`).
- Output follows ARFC 0019 and `product/principles.md` T rules, including T-0091 review F2 and F3.
- Tests: the CLI against fixed data for each command, and errors that lead somewhere.

## Out of scope

- `crates/alloyd/**` and the other crates, which are T-0136's. If the CLI needs a change there, name it in the report.
