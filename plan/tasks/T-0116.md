## Goal

`alloy-link` follows ARFC 0003's crossed rekey rule (T-0115). No arrival order of two crossed rekey handshakes blackholes either direction, and no previous receive key outlives what the spec allows.

## Scope

- Read only ARFC 0003 sections 3.3 and 3.4 and the review.
- Replace the `moved_on` logic and previous-key retention that findings F1 and F2 of `plan/reports/T-0104.reviewer.2.md` describe with the rule T-0115 specifies.
- Tests: every arrival order in T-0115's table, each one asserting delivery both ways within the spec's bound; a seeded run of 1,000 crossed rekeys under loss and reordering with no blackhole longer than the bound.

## Out of scope

- Anything else in `alloy-link`.

cargo test -p alloy-link --locked   # expected: passes, including every arrival order
