## Goal

Two tasks that each add one row to the same index file can run in parallel. Today every task that writes an ADR touches `adr/README.md`, so no two such tasks are ever disjoint.

## Scope

- In `agent/protocol/tasks.md`, name the index files (`adr/README.md`, `spec/README.md`, `product/briefs/README.md`, `research/README.md`) as shared append-only paths: a task may add rows to them and may not edit or reorder existing rows.
- Exclude these paths from the disjointness check in the readiness rules.
- Say who resolves a merge conflict in a shared index: the lead, at merge, by keeping both rows. If that conflicts with the lead's write rules in `agent/roles/lead.md`, report it as a `process-issue` instead of editing that file.

## Out of scope

- Other shared files such as `Cargo.toml`, `Cargo.lock`, or `deny.toml`.
- Enforcement in `check-repo`.

## Acceptance

```
grep -n "adr/README.md" agent/protocol/tasks.md   # expected: named as a shared append-only path
```
