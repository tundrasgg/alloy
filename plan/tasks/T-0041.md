## Goal

The console loads in the browsers ARFC 0019 section 3.2.4 names, on a cluster with or without a public name, because the API CA key and the API server certificate chain use a key type those browsers verify.

## Scope

- ARFC 0002 section 2: change the API CA key from Ed25519 to ECDSA P-256, per R-0006, or justify another browser-verifiable type. Every place that names the API CA key type or its fingerprint (join tokens, login codes) stays consistent.
- ARFC 0008 section 3.8: the API server certificate and every signature in its chain use that type.
- `agent/eng/crypto.md`: add ECDSA P-256 to the primitives table, scoped to the API CA and TLS certificates only. Ed25519 stays for everything else.
- Write ADR 0048 and index it.

## Out of scope

- Mesh keys, node records, and the cluster key, which stay Ed25519.
- The ACME path for clusters with a public name, unless it is affected.
