## Goal

Tests that hold the simulator to ARFC 0005: same seed same trace, different seeds differ, every fault behaves as specified, and the time budget holds.

## Scope

- Same seed, two runs, identical trace hash, across 100 seeds.
- Distinct seeds give distinct schedules.
- Each fault in section 3.3: injected, observed, and removed.
- Crash loses exactly the unsynced writes.
- One virtual hour of 100 hosts within the wall time bound.
- The runtime seam suites from T-0008 run against the `mem` implementations.
