## Goal

Every push to `main` runs `cargo xtask check-commits` over the commits it adds, and fails when any of them breaks the format in `agent/eng/git.md` or the D-0016 path lock.

## Scope

- On `push` to `main`, run `cargo xtask check-commits <before>..<after>` using the push event's before and after commits. When the before commit is not an ancestor (a new branch or a forced update), check from `78d3175` instead (D-0019).
- Fetch enough history for the range to resolve.
- Pull requests do not run it: task branch commits are free-form (`agent/eng/git.md`).

## Out of scope

- Commit hooks.

## Acceptance

```
actionlint .github/workflows/ci.yml          # expected: exits 0 (official rhysd/actionlint; if it cannot run, report it and the lead runs it)
cargo xtask check-commits 78d3175..main      # expected: exits 0
cargo xtask ci                               # expected: exits 0
```

## Notes

D-0019: commits up to and including `78d3175` predate enforcement and are not checked.
