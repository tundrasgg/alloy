## Goal

`alloy-crypto` provides all the cryptography the AL mesh protocol needs, so `alloy-link` can run handshakes and sessions without touching a primitive. That means four parts of ARFC 0003:
- the Noise `IKpsk2` handshake of section 3.1;
- the session key derivation and erasure of section 3.3 and ADR 0043;
- the `mac1`, `mac2`, cookie and cookie reply of section 3.1;
- transport sealing and opening as section 3.4 states.

## Scope

- Build the `IKpsk2` handshake state from primitives, not from `snow` (D-0032). The primitives are X25519, XChaCha20-Poly1305, BLAKE2s, and HMAC-BLAKE2s HKDF, per the Noise specification revision 34. Both roles:
  - The initiator writes the initiation and reads the response.
  - The responder reads the initiation, reveals the initiator's static key, takes the pre-shared key, then writes the response.

  The result is the section 3.3 session keys (`i2r`, `r2i`, and the 14-byte `salt`) and nothing else. Every intermediate secret is zeroized as ADR 0043 states.
- `mac1`, `mac2`, the cookie and the cookie reply exactly as section 3.1 states. Transport seal and open with the section 3.4 nonce layout. MAC checks are constant time (`subtle`).
- The caller supplies every random byte: ephemeral private keys, cookie secrets, and cookie reply nonces. `alloy-crypto` takes them as arguments and never reads a generator (crypto rule 4).
- Key types zeroize on drop and print no secret through `Debug`.
- Add the crates from `agent/eng/crypto.md` that this needs (`x25519-dalek`, `chacha20poly1305`, `blake2`, `hkdf` or `hmac`, `subtle`, `zeroize`), and their trees, to `deny.toml`. The report gives each license.
- Tests:
  - The primitives against their published vectors: RFC 7748 for X25519, the XChaCha20-Poly1305 draft vector, and RFC 7693 for BLAKE2s.
  - A full handshake between initiator and responder that yields equal keys.
  - Failure for each of: a wrong pre-shared key, a tampered byte in each field, and a wrong static key.
  - Erasure that the API makes observable, for example by consuming the state.
- Fold the T-0074 review note: the `Hasher` doc states its buffer accurately.

## Out of scope

- Message framing, timers, retries, session tables, and replay windows, which belong to `alloy-link`. Also the hybrid key exchange slot.

## Acceptance

```
cargo test -p alloy-crypto --locked   # expected: passes, including primitive vectors and handshake round trips
cargo deny check                      # expected: exits 0
cargo xtask ci                        # expected: exits 0
```
