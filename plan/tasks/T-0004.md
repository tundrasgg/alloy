## Goal

Answer: does the current Cloud Hypervisor release support everything ARFC 0011 asks of the first `hypervisor` implementation?

## Scope

- For each of these, state supported, partial, or unsupported, with the version and a source: aarch64 and x86_64, vhost-user-net, vhost-user-blk, direct kernel boot and UEFI boot, hotplug of disks and network devices, live migration and its limits, its control API, seccomp and Landlock support, memory ballooning, serial console access, Windows guests.
- Report its license and the licenses of the firmware it needs.
- Report measured or documented boot time to first guest instruction.

## Out of scope

- Choosing a different hypervisor.
- Writing integration code.
