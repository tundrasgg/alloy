## Goal

`ui/console/` holds the Alloy Console shell and its first screens, running on fixture data, as PB-0002 shows them:
- Overview, with the single-anchor warning;
- Nodes;
- Mesh;
- VPCs and Instances, including the create-instance dialog and its live status lines.

It looks and feels like PB-0002 and `product/principles.md`: dense, keyboard first, fast, and quiet, in the manner of Linear and Raycast.

## Scope

- Toolchain, by D-0066:
  - TypeScript in strict mode, Vite, and Preact;
  - no CSS framework and no component library: one small hand-written design system of tokens, with light and dark themes;
  - a lockfile committed;
  - every dependency pinned to an exact version.
- The shell:
  - navigation;
  - the `g`-prefixed shortcuts, and `Ctrl+K` with the command palette;
  - the `[Copy]` command line, which shows the CLI command for every action;
  - empty, loading, stale-with-age (ARFC 0019 section 6), and error states.
- Data: one typed data module behind an interface. Its only implementation in this task serves fixtures, shaped after the API messages in `proto/` where they exist and after PB-0002 where they do not. No network code, since the browser wire form is T-0139's.
- `cargo xtask console`:
  - installs the locked dependencies;
  - type-checks;
  - runs the tests;
  - builds `ui/console/dist`.
  It is not yet part of `cargo xtask ci`.
- Tests: the palette, the shortcuts, and each screen rendered from its fixtures.
- Meet ARFC 0019 section 7's initial load bound, and report the built size.

## Out of scope

- Network transport, authentication, the bridge, and serving from `alloyd`.

## Acceptance

```
cargo xtask console   # expected: exits 0 and reports the built size
cargo xtask ci        # expected: exits 0
```

## Notes

Off the rung path, in parallel with M11. No size target (D-0064). Gets one review, with screenshots of each screen in the report.
