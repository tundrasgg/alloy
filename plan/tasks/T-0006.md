## Goal

ARFC 0001 and ARFC 0005 gain exact trait signatures for the seam registry and the five runtime seams, precise enough that an interface task is transcription.

## Scope

- Rust signatures for `Clock`, `Net`, `DiskIo`, `Rng`, `Spawn`, and `Runtime`, with error types, batch shapes, and cancellation behavior.
- Rust signatures for the registry in `alloy-seam`, the configuration value type, and the live swap protocol methods.
- The event trace format and how the trace hash is computed.
- Close open question 1 of ARFC 0005 using R-0001, with ADR 0036 recording the choice.

## Out of scope

- Implementations.
- NAT presets (T-0005 feeds a later task).
