## Goal

The specs fix a default UDP mesh port and say how the native API and the `stream` underlay share TCP 443 on a node that is both anchor and control.

## Scope

- Choose the default mesh port. PB-0001 proposes UDP 7270. Check it against the IANA service name and port number registry and say what the registry shows, with a source. Make it configurable with `--mesh-port`.
- Specify sharing TCP 443 between the API (ARFC 0008) and the `stream` underlay (ARFC 0004) by ALPN: the protocol identifiers, and what happens with an unknown or missing ALPN value.
- The API port defaults to 443 and is configurable with `--api-port`, on `init` and on `join` (PB-0001 Errors, "Port in use").
- ARFC 0008 section 3.8: a client that connects by address is presented a chain ending in the API CA certificate, even on a cluster that also has an ACME certificate, so login codes work there.
- Write ADR 0042 and index it.

## Out of scope

- Everything else in PB-0001 (T-0022, T-0023).
