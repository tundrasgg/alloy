## Goal

The `native` conformance harnesses follow ARFC 0005 clause 3.1.15 as D-0062 keeps it. On Windows, a process that may not name `Administrators` as owner gets `Failed` from `native`, and the harness checks that refusal instead of failing. On an elevated Windows process, and on Linux, every check runs as now.

## Scope

- Start from `task/T-0121`: branch `task/T-0128` from it, then merge main.
- In both suites' `native` harness: detect whether the process can create a `Private` file through `disk-io`. When it cannot, assert that building `native` fails with the clause 3.1.15 error and that nothing was created, print one line saying the `native` checks did not run and why, and skip them. Never skip silently, and never report them as passed.
- The `mem` checks are unchanged.

## Out of scope

- `crates/`.

## Acceptance

```
cargo xtask ci   # expected: exits 0 on an unelevated Windows host, with the skip line printed
```
