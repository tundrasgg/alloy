## Goal

A Cargo workspace exists at the repository root with a pinned toolchain and an `xtask` crate. `cargo xtask ci` runs formatting, lints, tests, and dependency checks and is the single gate.

## Scope

- Workspace `Cargo.toml` with shared lints, edition 2024, and `license = "MIT OR Apache-2.0"`.
- `rust-toolchain.toml` pinned to the current stable release, with `rustfmt` and `clippy`.
- `xtask` with `ci` running, in order: `fmt --check`, `clippy -D warnings`, `test --workspace`, `deny check`, `xtask check-repo` (a stub that exits 0 until T-0002).
- `deny.toml` as an allowlist per `agent/eng/deps.md`, holding only what `xtask` needs.

## Out of scope

- Any product crate.
- CI service configuration files.
- `check-repo` rules (T-0002).

## Acceptance

```
cargo xtask ci      # expected: exits 0
cargo deny check    # expected: exits 0
```
