## Goal

CI checks commit messages on every push to `main` while still running exactly one command, `cargo xtask ci`, as ADR 0037 requires.

## Scope

- Start your branch from `task/T-0072`, not from main: merge `task/T-0072`, then main, before any edit.
- `cargo xtask ci` gains an option (for example `--commits <rev-range>`) that runs `check-commits` over that range as one more gate step, after the existing steps.
- The workflow passes that option on pushes to `main`, with the before..after range and the `26eef5f` fallback (D-0027), and runs no other command. Resolve finding F1 of `plan/reports/T-0072.reviewer.1.md` and any other finding there.

## Out of scope

- Commit hooks, pull request checks.

## Acceptance

```
git merge-base --is-ancestor task/T-0072 HEAD && echo ok   # expected: ok
cargo xtask ci --commits 26eef5f..main                      # expected: exits 0
actionlint .github/workflows/ci.yml                         # expected: exits 0 (official rhysd/actionlint; if it cannot run, report it and the lead runs it)
grep -c "cargo xtask" .github/workflows/ci.yml              # expected: the workflow invokes only cargo xtask ci
```
