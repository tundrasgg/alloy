## Goal

ARFC 0007 makes no claim that bounds what root on a control node can see. It states plainly that root there can read every org's data, and which of its actions are audited.

## Scope

- Replace every sentence in clauses 3.3, 3.10, and section 8 that limits the local admin's reach to tenant data to "one way", "only", or a listed set of ways. Say instead: user id 0 on a control node can read all tenant data, including control plane state on its disks and any data on nodes it controls. This follows from ARFC 0020 section 2.2, which already trusts it.
- State exactly what is audited: every call through the local admin socket (ARFC 0018 clause 3.3.1), and nothing done outside the API, such as reading disks directly. Fix the clause 3.3 reason that misstates ARFC 0018 clause 3.3.1 (review F3).
- Resolve review notes F4 (storage nodes, object and registry data) and F5 (a call whose target is an org) with the same plain statement or a sentence each.

## Out of scope

- Reducing the local admin's power (D-0020).
