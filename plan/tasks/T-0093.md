## Goal

`tests/e2e/` holds the M11 rung 1 check: from a clean state, one command per machine installs Alloy on two Linux nodes and a Windows client, the check verifies the install, and the uninstall leaves each machine as it was.

## Scope

- A driver that runs the check from one machine (the Windows client) against the Linux nodes over SSH as root, and against the local Windows machine from an elevated PowerShell. Machines are given only by parameters: an SSH destination per Linux node, a flag marking a Proxmox VE node, and the release version to install. No host name, address, user, or path of any particular pilot appears in the repository.
- For each machine, per ARFC 0017 clause 3.17.6:
  1. Take a host snapshot.
  2. Run the one-line install from the release's pinned URL (clause 3.15).
  3. Check that `alloy version` prints the version, that the service exists and is disabled, and that the snapshot differs only as clause 3.17.6 allows.
  4. Run the uninstall (clause 3.16).
  5. Check that the snapshot equals the first one.
- Also check that a second install run changes nothing and exits 0, and that a second uninstall exits 0.
- On the Proxmox VE node, also compare the guest list and states, `/etc/network/interfaces`, and the `/etc/pve` digests before and after.
- The driver prints one PASS or FAIL line per check, ends with a summary, and exits non-zero on any failure. It never runs a command on a remote machine other than the snapshot commands, the install, the checks, and the uninstall.
- A `README.md` in `tests/e2e/` that says how to run each rung's script, with placeholders for the machines.

## Out of scope

- Running it against real machines: the lead does that. Later rungs.

## Acceptance

```
sh -n tests/e2e/*.sh                                   # expected: every shell script parses
pwsh -NoProfile -Command "& { $null = [System.Management.Automation.Language.Parser]::ParseFile('tests/e2e/rung1.ps1', [ref]$null, [ref]$e); if ($e) { exit 1 } }"   # expected: exits 0 (or Windows PowerShell)
cargo xtask ci                                         # expected: exits 0
```

## Notes

Write from the spec. The snapshot must drop counters, statistics, and timestamps, as clause 3.17.6 says, or the comparison will fail on noise.
