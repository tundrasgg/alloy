## Goal

`thiserror` and `proptest`, which `agent/eng/deps.md`, `agent/eng/rust.md`, and `agent/eng/testing.md` already name as the settled choices, are on the `deny.toml` allowlist with their full dependency trees, so crates can use them.

## Scope

- Add `thiserror` and `proptest` (as a dev-dependency choice) and every crate in their trees to `deny.toml`'s allowlist, each checked against the license list in `agent/eng/deps.md` and RustSec advisories.
- Declare both in `[workspace.dependencies]` with pinned versions so crates inherit them.
- Report each crate added, its license, and the `cargo deny check` output.

## Out of scope

- Changing any crate to use them (follow-up tasks per crate).

## Acceptance

```
cargo deny check   # expected: exits 0
cargo xtask ci     # expected: exits 0
```
