## Goal

ARFC 0004 sections 3.2 to 3.4 and 8 have one reading, the path class rule in section 3.3 agrees with it for every single and layered ARFC 0005 axis combination, and no traffic toward an unverified endpoint exceeds the bound section 8 states.

## Scope

- F1 (block in `plan/reports/T-0031.reviewer.1.md`): state whether, and from when, a verified peer-reflexive candidate is probed. Prefer the reading under which ADR 0039's stated counts hold; if no sound design keeps them, write ADR 0049 superseding ADR 0039 and say why.
- F2 (block): an authenticated packet from a new source endpoint does not move the return path until that endpoint is verified, or what is sent there before verification is bounded. Section 8 states only bounds that hold for every packet sent toward an unverified endpoint.
- F3: the `usable` condition is stated in terms of what each node itself observes.
- F4: the layered reduction has one reading, which agrees with section 3.2 on all layered cases.
- F5: the 5 s direct bound states the signaling latency it assumes, or the probing window holds at the latencies the bound covers.
- Probe set rate bound: section 3.4 starts a probe set whenever candidates change, with no bound; a compromised peer can repeat probe rounds toward a third party. Bound it and state the behavior beyond the bound.
- For F1, F3, and F4, the report gives the model and the counts that show agreement (the reviewer's method is in the review report).

## Out of scope

- Probe bytes and probe replay in ARFC 0003 (T-0038).
- The default mesh port and ALPN (T-0024).
