## Goal

ARFC 0007 meets I-21 for access key lineage, and every guarantee its section 8 and ADR 0041 state about login codes and revocation actually holds.

## Scope

- F1 (block in `plan/reports/T-0023.reviewer.2.md`): state a bound on revoked access keys kept for lineage and on the records of what each session token and temporary key derives from, and the behavior at each bound. The descent and revocation guarantees of clause 3.9.7 and section 8 must still hold under the bound.
- F2: no credential that derives from a temporary key can issue a login code, so the stated reason holds.
- F3: a request with `descendants: true` on an already revoked key revokes its descendants, so the section 8 remedy survives a re-login through `replaces`.
- F4: clause 3.9.4 says whether policy evaluation runs at exchange, and if so with which action and resource; if not, that the listed checks are the whole authorization.
- Notes F5 and F6: address them if the fix is a sentence; otherwise list them as `follow-up` in the report.
- ADR 0041 is accepted and is not edited. Make each guarantee it states true in ARFC 0007. If one cannot be made true, report `blocked` with one question and its options.

## Out of scope

- ARFC 0002 and ARFC 0019 (T-0022).
- Changes to ARFC 0020.
