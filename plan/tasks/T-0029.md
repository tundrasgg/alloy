## Goal

ADR 0044 records the pilot's answer to a pivotal question: Alloy's install scripts are served from GitHub Releases of `tundrasgg/alloy`.

## Scope

- Write ADR 0044, status `accepted`, at most 40 lines. Decision: `install.sh` and `install.ps1` are release assets of `tundrasgg/alloy`, fetched from `https://github.com/tundrasgg/alloy/releases/latest/download/install.sh` (and `install.ps1`); a pinned version uses `releases/download/<tag>/`. No other download host.
- Consequences to state: the release process must attach both scripts to every release; PB-0001's `<download-host>` placeholder becomes this URL.
- Index it in `adr/README.md`.

## Out of scope

- Editing PB-0001 (a product task does that).
- Release automation.

## Notes

The pilot chose GitHub Releases over a subdomain of an existing domain and over a dedicated Alloy domain, in the lead session that cut this task. Reason given with the option: no new domain to own or run, and the URL stays valid as long as the repository does. D-0008 is the provisional record.
