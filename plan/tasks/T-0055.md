## Goal

`tests/conformance/wire/` checks `alloy-wire` against ARFC 0003 sections 3.1, 3.4, and 3.5 from the spec alone: exact byte vectors for each message type and every drop rule.

## Scope

- Hand-built byte vectors for messages of types 1 to 4, the inner frame, and the fragment body, derived from the spec tables, each decoded and re-encoded through the public API of `alloy-wire`.
- One rejection case per fixed value and drop rule in section 3.1, and per bound in sections 3.4 and 3.5.

## Out of scope

- Reading the implementation beyond its public API.
- Probe messages (type 5).

## Acceptance

```
cargo test --test conformance_wire   # expected: passes against alloy-wire on main
cargo xtask ci                       # expected: exits 0
```
