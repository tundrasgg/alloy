## Goal

Every push to `main` runs `cargo xtask ci` to completion and reports a verdict, while superseded pull request runs are still cancelled.

## Scope

- Change the `concurrency` setting in `.github/workflows/ci.yml` so that runs on `main` never share a group with a newer run (for example, a group keyed by commit SHA for pushes), as finding F1 in `plan/reports/T-0016.reviewer.1.md` requires.
- Keep the comment in the workflow accurate.

## Out of scope

- Any other workflow change.

## Acceptance

```
actionlint .github/workflows/ci.yml   # expected: exits 0, no output (official rhysd/actionlint release; if it cannot be run, report it and the lead runs it)
cargo xtask ci                        # expected: exits 0
```

## Notes

GitHub documents that a pending run in a concurrency group is cancelled when a newer run is queued, regardless of `cancel-in-progress`.
