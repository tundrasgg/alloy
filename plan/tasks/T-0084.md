## Goal

Every case in `tests/conformance/rt` that ARFC 0005 applies to the `os` implementations runs against them through `OsHost` and `register_os`, and passes.

## Scope

- An `os` harness in `tests/conformance/rt` that builds each seam through `register_os` on an `OsHost` and runs the existing cases for `clock`, `rng`, `spawn`, `net`, and `disk-io` against it.
- Some cases stay out of the `os` run: those the ARFC makes `mem`-only, and those that cannot be triggered deterministically on a real OS. Each gets a one-line reason in the harness, citing its clause.
- New cases for the `os`-only clauses of section 3.1, for example `OsDiskIoConfig.root` validation and `ShuttingDown` after `OsHost::shutdown`.

## Out of scope

- The `mem` harness (after T-0078), and any change to `crates/`.

## Acceptance

```
cargo test -p conformance-rt --locked   # expected: passes, with the os harness running every applicable case
cargo xtask ci                          # expected: exits 0
```
