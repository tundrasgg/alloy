## Goal

On Windows, the uninstall of a clean `client` install exits 0. On the first real run it removed everything correctly but exited 1.

## Scope

- Evidence from the first real run of `v0.0.1-preview.1`, an elevated Windows PowerShell 5.1 on Windows 11 build 26300, after `irm .../install.ps1 | iex`:
  - The installed `uninstall.ps1` removed every file and directory, the service, and the `PATH` entry. The host snapshot afterwards equals the one taken before the install.
  - It then printed `The uninstall script failed unexpectedly: Cannot bind argument to parameter 'LiteralPath' because it is an empty array.` and exited 1.
  - A second uninstall through `install.ps1 -Uninstall` exited 0.
- Find the call that receives an empty value and fix it, likely one about the data directory, the marker, or the manifest holder after the manifest is gone. Check every other `-LiteralPath` call that can receive an empty or `$null` value, in `uninstall.ps1` and `install.ps1`.
- A check in `check.ps1` (or the dry run) that a clean install followed by an uninstall exits 0 on Windows, run elevated if your host allows it. Otherwise run it with the install paths redirected to a temporary root, and say which.

## Out of scope

- Anything else in `packaging/`.

## Acceptance

```
sh packaging/check.sh   # expected: every check passes
cargo xtask ci          # expected: exits 0
```

## Notes

The lead reruns the real Windows install and uninstall as acceptance. Under 100 changed lines; it gets a review only if it changes more than the failing path.
