## Goal

A cluster always keeps at least one enabled user with `cloud-admin` that the local admin path can reach, and ADR 0041 is marked as superseded by ADR 0050.

## Scope

- ARFC 0007 states who may grant and remove the cluster role `cloud-admin`, and whether the last enabled holder can lose it or be disabled. A thief holding the only admin's key must not be able to take the cluster beyond the local admin recovery path (`spec-issue` in `plan/reports/T-0044.architect.1.md`). Check the rule against ARFC 0020.
- Set ADR 0041's status line to `superseded by 0050`, the one edit `agent/protocol/decisions.md` allows, and mark its row in `adr/README.md` accordingly. This task holds `adr/README.md` exclusively for that row edit (`agent/protocol/tasks.md`, Shared index files).
- ADR 0052 is allocated if the `cloud-admin` rule is a new decision.

## Out of scope

- CLI commands (T-0045).
