## Goal

`tests/e2e/host-snapshot.ps1` leaves out exactly the firewall rules that clause 3.17.6, as T-0150 amends it, leaves out.

## Scope

- Filter the `Get-NetFirewallRule` section as the clause says, and describe it in the header, next to the `Get-Service` note.
- Nothing else in the snapshot changes.

## Acceptance

From an elevated Windows PowerShell 5.1 on a machine with such rules:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tests\e2e\host-snapshot.ps1 > a.txt   # the run's own scratch, not in the repository
cargo xtask ci                                                                            # expected: exits 0
```

The report shows the count of rules before and after the filter, and that no rule for a program under the Alloy install directory is left out.
