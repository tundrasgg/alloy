## Goal

PB-0002 describes the Alloy Console well enough for an architect to specify it and a developer to build it. It covers:
- the first screens, those the M11 rungs make real: nodes, then VMs, VPCs, and the mesh;
- the interaction model of `product/principles.md` C1 to C19 (keyboard first, a command palette, density, speed);
- what the console needs from the API in a browser.

## Scope

- Read only ARFC 0019 section 3.2, ARFC 0008 sections 2 and 3, R-0006, R-0007, and the principles.
- The brief:
  - users and jobs;
  - the screens in priority order, each with its data and its actions, which must equal the CLI's (principle 7);
  - the command palette's commands;
  - keyboard map, URL per screen, live updates, empty and error states, and themes;
  - wireframes in text.
- What the browser needs from the API: list it as `spec-issue` entries for ARFC 0008 and 0019, which the brief cannot change. That covers how a browser authenticates, which wire form it calls (R-0007: gRPC-web, Connect, or JSON over HTTP), how the console is served and pinned (ARFC 0019 section 2), and watches for live updates.
- Allocate the brief id PB-0002 and add its index row.
