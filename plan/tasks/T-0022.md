## Goal

ARFC 0002 and ARFC 0019 specify init, join, login codes, and the related CLI exactly as PB-0001 asks, or the report says which requested change was refused and why.

## Scope

- Apply every change PB-0001 "Requested design changes" lists under ARFC 0002 and ARFC 0019, except those listed under Out of scope.
- That covers: optional `--advertise` with its default; what `init` creates; the login code format; the join token checksum; joiner defaults and flags; the version check before the secret; refusal reasons only after the secret matches; approval with `node approve` and `node reject`; `Conflict` on an already joined machine and `node leave`; the standing warning for a lost advertise address; the CLI changes to `login`, warnings, standing warnings, and `node list`.
- Write ADR 0040 for the behavior changes and index it.

## Out of scope

- The local admin path for root on a control node, and access keys for users (T-0023).
- The default mesh port and TCP 443 sharing (T-0024).
- The download host. The pilot decides it.
