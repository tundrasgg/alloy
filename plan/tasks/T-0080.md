## Goal

A node never sends session traffic to an endpoint, nor moves its return path or relay to one, until that endpoint has echoed a fresh challenge from that node. Every table this needs has a stated bound. The redirection an attacker can cause is then nil, and section 8 says so.

## Scope

- Replace the timing-based move rules (the "1 s without a transport packet" rule and its variants) with one rule: verify by challenge echo, then move. State it for direct paths, relayed paths, and an anchor's home sessions.
- Resolve `plan/reports/T-0043.reviewer.2.md`: F1 and F3 (block), F2 and F4 (fix), each resolved or made moot by the simpler rule, with the reason stated.
- Every per-endpoint and per-challenge table has a numeric bound in section 7 and a stated behavior at the bound (I-21).
- Keep the path class results (34 of 81 single, 872 of 7,290 layered) or state the new counts with the model used.
- ADR 0061 superseding ADR 0049 if the decision changes; restate what still holds.

## Out of scope

- Probe bytes (ARFC 0003), the default port and ALPN (T-0024).
