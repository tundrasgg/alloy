## Goal

`cargo xtask check-commits` reads footers and trailers exactly where git does, from the last paragraph of the message, so a `Key: value` line inside the body is not mistaken for a trailer.

## Scope

- The `trailers`, `footers`, and `task-id` rules take footers only from the message's last paragraph, matching `git interpret-trailers --parse`, including the no-space form `Key:value` that T-0046 adds.
- Add a passing fixture whose body contains a `T-0006: ...` line in a middle paragraph, and keep a failing fixture for a stray trailer in the last paragraph.

## Out of scope

- Other commit rules.

## Acceptance

```
cargo test -p xtask                          # expected: passes, with the new fixtures
cargo xtask check-commits 78d3175..main      # expected: exits 0, including commit 9cb9b92
cargo xtask ci                               # expected: exits 0
```

## Notes

Observed false positive: commit `9cb9b92` on main has the body line `T-0006: one block ...` in its middle paragraph and is reported by the `trailers` rule (`plan/reports/T-0051.developer.1.md`).
