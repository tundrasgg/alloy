## Goal

Answer: how should the TypeScript client the console uses be generated from Alloy's Protocol Buffers definitions, so that ARFC 0008 section 3.10 ("the CLI and console use only generated clients") holds for the console?

## Scope

- Candidate generators and runtimes (for example protobuf-es with Connect, ts-proto, or grpc-web), with license, maintenance activity, bundle size, browser transport support, and how each handles streaming and error details.
- Which wire transports each needs from the API server, and whether the API as specified in ARFC 0008 can serve them without a proxy.
- How the generated client would be produced in this repository's toolchain, given that `cargo xtask` is the only build entry point (D-0002).

## Out of scope

- The console UI framework (M9 research).
- Choosing an option. That is a spec task after this note.
