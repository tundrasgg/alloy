## Goal

The NAT spec changes on branch `task/T-0021` no longer carry the three findings in `plan/reports/T-0021.reviewer.1.md`, and land on main together with T-0021 as one commit.

## Scope

- Start your branch from `task/T-0021`, not from main: merge `task/T-0021` into `task/T-0031` before any edit. T-0021's work and its ADR 0039 are not yet on main.
- F1 (block): the section 3.3 path class rule, its "every other pair" sentence, and ADR 0039's consequences agree with what section 3.2 produces for every combination of ARFC 0005 axis values, or the rule limits itself explicitly and says how the others are decided. ADR 0039 is not yet accepted on main, so correct it on the branch.
- F2 (block): traffic a node sends toward a source endpoint it has not verified is bounded so a replayed or spoofed probe yields no amplification toward a third party. ARFC 0004 section 8 and ADR 0039 state the bound that holds. If no design both keeps the section 3.2 mixed-pair result and removes the amplification, do not weaken ARFC 0020: report `blocked` with one question and its options.
- F3 (fix): ARFC 0005 states what keeps the relay route open to a node behind a NAT with a timeout under 25 s, or limits the `short-timeout` delivery expectation to what ARFC 0004 guarantees.
- ADR 0045 is allocated if a new decision is needed beyond correcting ADR 0039 on the branch.
