## Goal

`agent/eng/crypto.md` names a P-256 source that meets ARFC 0002 section 2 and allows every P-256 signature the specs require, and invariant I-07 says whether it covers the deterministic ECDSA nonce.

## Scope

- F1 (`plan/reports/T-0041.reviewer.1.md`): the P-256 row names the source R-0008 shows meets RFC 6979 and injected randomness, and the `rustls` provider. Record the provider choice in ADR 0053.
- F2: the P-256 scope allows the PKCS#10 CSR signature that the ACME path in ARFC 0008 clause 3.8 requires.
- F4 (note): I-07 states whether it covers ECDSA `k`, and if so that `k` repeats only for an identical key and message, which yields an identical signature.

## Out of scope

- ARFC 0002 wording (T-0045 takes note F3).
