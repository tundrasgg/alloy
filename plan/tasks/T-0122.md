## Goal

The ADRs say what the plan does. ADR 0008 says the simulator and NAT lab are built before any feature. Since D-0034 and D-0044 the plan builds the M11 rungs on real hardware first, with the simulator paused. ADR 0067 supersedes ADR 0008.

## Scope

- ADR 0067 keeps, unchanged, the rule that all I/O goes through `alloy-rt` traits and that lint rejects direct calls. That rule is what lets every crate run on the simulator later.
- It states when the simulator gates work instead of "before any feature". For example: before a stable release, and before any consensus or mesh path change is called done after M11. State what runs on the simulator until then.
- It names what a crate built before the simulator must still do: no direct I/O, and deterministic for a given input sequence.
- ADR 0008's status line becomes `superseded by 0067`, and its index row changes accordingly.

## Out of scope

- ARFC 0005's text, and the simulator tasks themselves.
