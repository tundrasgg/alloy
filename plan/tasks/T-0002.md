## Goal

`cargo xtask check-repo` enforces the mechanical rules in `agent/` so that agents cannot break them unnoticed.

## Scope

- Reject vendor instruction files: `CLAUDE.md`, `CLAUDE.local.md`, and any other instruction entry file besides `AGENTS.md`, at any depth.
- Reject the banned code patterns in `agent/core/4-evidence.md` in `crates/`, with file and line.
- Reject direct clock, network, file, thread, and randomness calls outside `alloy-rt` and `alloy-sim` (the list in `agent/eng/rust.md`).
- Reject `unsafe` outside the crates listed in `agent/eng/rust.md`.
- Path lock: given a base ref, fail when a branch named `task/T-NNNN` whose task type is not `verify` changes the paths locked in `agent/eng/testing.md`.
- Validate front matter of every file in `plan/tasks/` and `plan/reports/` against the templates, and check that every path in `reads` exists for each task the board marks `active`.
- Check that relative links and backticked repository paths in `agent/`, `spec/`, `adr/`, and `plan/` resolve.
- Reject date-like strings (`YYYY-MM-DD`) in `plan/`, `adr/`, `spec/`, and `agent/`, except inside code blocks.
- A fixture directory under `xtask/tests/fixtures/` with one failing and one passing case per rule.

## Out of scope

- Semantic checks that need judgment.
- Fixing violations.

## Acceptance

```
cargo xtask check-repo                 # expected: exits 0 on main
cargo test -p xtask                    # expected: one passing test per rule fixture
```
