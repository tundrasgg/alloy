## Goal

`tests/e2e/rung2.ps1` reruns the M11 rung 2 check from a clean state:
- install;
- `alloy init` on one Linux node;
- `alloy join` on the other Linux node and on the Windows client;
- `alloy node list` on each machine shows all three nodes `healthy`;
- then uninstall with purge returns every machine to its snapshot.

## Scope

- Reuse the rung 1 driver's structure: SSH as root to each Linux node with scripts over stdin, the local elevated Windows part, and the host snapshot with its self-check.
- Steps:
  1. Install a given release on every machine.
  2. `init` on the node given as the first control node.
  3. Take its join token from the output.
  4. `join` the second node and the client.
  5. Within a stated timeout, `node list --output json` on each machine shows three nodes with the expected roles (a client node shows none) and status `healthy`.
  6. Uninstall with `--purge` (the client and the second node leave first, as ARFC 0017 clause 3.16 says), then compare snapshots.
- Coexistence while joined (clause 3.17.6, second rule): the snapshot of a joined node differs from the pre-install one only in reserved objects.
- One PASS or FAIL line per check, and a SUMMARY.

## Out of scope

- Mesh paths (rung 3) and anything in `crates/`.
