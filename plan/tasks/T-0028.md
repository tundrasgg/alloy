## Goal

ARFC 0011 clauses 2.5 and 2.7 state Landlock's thread scope and premises correctly, and ARFC 0020 lists ADR 0038 in its decisions.

## Scope

- Clause 2.5 (review finding F1): state which threads the Landlock rule set covers and from when. Cloud Hypervisor v54.1 applies it at `vm_create` to that thread and the threads it starts afterwards, without `LANDLOCK_RESTRICT_SELF_TSYNC`. Either require every thread before the first guest instruction and record that v54.1 does not meet it, or state the scope v54.1 provides and rely on clauses 2.1 to 2.3 for the other threads.
- Clause 2.7 (F2): state the Unix socket premise as a property of the Landlock ABI the `hypervisor` implementation uses (v54.1 uses ABI 3), not of Landlock in general. ABI 6 scopes abstract Unix sockets and ABI 9 restricts connecting to pathname Unix sockets.
- ARFC 0020 header (F4): add 0038 to `Decisions`. No other change to ARFC 0020.
- ADR 0038 is accepted and not edited. Where its summary of read-only files (F3) is narrower than clause 2.5, the ARFC governs (`agent/core/1-authority.md`); say so in the report.
- If the wording of clause 2.5 or 2.7 changes required behavior, write a new ADR and report the number you need as a `blocked` question. A clarification needs no ADR.

## Out of scope

- Conformance tests for section 2 (review finding F5 is recorded for the M3 verify task).
- Other sections.
