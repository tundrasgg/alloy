## Goal

The ARFC 0003 conformance suite holds fixed handshake vectors, computed independently of `alloy-crypto`, and `alloy-crypto` must reproduce them byte for byte.

## Scope

- Fix the inputs: static keys, ephemeral keys, the pre-shared key, payloads, and cookie inputs. From them, compute the expected:
  - initiation and response Noise bytes;
  - `mac1` and `mac2`;
  - cookie reply;
  - `i2r`, `r2i`, and `salt`;
  - one sealed transport packet.
- Compute the vectors with an independent implementation, for example a script that uses another language's libraries, and record in the report how. Commit the script if it needs nothing outside its language's standard library; otherwise quote its run.
- Tests that call `alloy-crypto`'s public interface and compare against those vectors, plus cases with a wrong key that must fail.

## Out of scope

- Any change to `crates/`.

## Acceptance

```
cargo test -p conformance-wire --locked   # expected: passes, including the handshake vectors
cargo xtask ci                            # expected: exits 0
```

## Notes

Fixed test keys are not secrets (crypto rule 8 covers real secrets). Label them as test values.
