## Goal

`alloy-wire` encodes and decodes the transport packet, inner frame, and fragment body in the compact layout ARFC 0003 specifies after T-0063, and exposes the counter reconstruction as a pure function.

## Scope

- Replace the transport header, inner frame, and fragment encodings with the new layout, keeping every decoder total and never panicking.
- A pure function that reconstructs a 64-bit counter from the truncated wire value and the receiver's current window position, per the spec rule, with property tests across the wrap and reorder bounds.
- Review note F1 in `plan/reports/T-0054.reviewer.1.md`: public docs state behavior, not history.
- Update the crate's tests and, if T-0061 has merged, its fuzz targets.

## Out of scope

- Cryptography and session state (`alloy-link`).
- Handshake messages, which are unchanged.

## Acceptance

```
cargo test -p alloy-wire   # expected: passes
cargo xtask ci             # expected: exits 0
```
