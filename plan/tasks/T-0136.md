## Goal

M11 rung 2 works end to end, as ARFC 0002 section 3.15 states:
- `alloy init` on a Linux node creates a cluster;
- `alloy join` adds a Linux node and a Windows client node;
- each machine runs `alloy login` with a code from `alloy login --issue-code`;
- `alloy node list` on every machine shows all three nodes `healthy`.

This one task replaces T-0131, T-0132, T-0133, and T-0112 (D-0064). Their task files hold the detailed scope and stay the reference.

## Scope

T-0129 and T-0130 are in review. Start by branching `task/T-0136` from main, then merge `task/T-0129` and `task/T-0130` into it. Merge main again whenever they land, and before you report.

All four cancelled tasks' Scope sections, built in this order, each part tested before the next starts:

   - T-0091 F2 and F3.
