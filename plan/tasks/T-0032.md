## Goal

A role dispatched with `round: 2` or later knows which branch to start from and which earlier reports to read, without the lead adding anything to the dispatch message.

## Scope

- In `agent/protocol/messages.md`, state for `round` greater than 1: the role continues on `task/T-NNNN` (its workspace starts from that branch, or merges it first if the harness creates workspaces from main), and reads every report for the task on main whose round is lower, including reviewer reports.
- State that the lead commits the reviewer's report to main before dispatching the next round, since review branches hold only the report.
- Keep the dispatch message format unchanged.

## Out of scope

- Changes to role files, unless a contradiction makes the rule unusable; then report it as a `process-issue`.

## Acceptance

```
grep -n -i "round" agent/protocol/messages.md   # expected: lines covering round 2 inputs and starting branch
cargo xtask ci                                  # expected: exits 0
```
