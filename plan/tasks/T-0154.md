## Goal

No `alloy` command on Windows opens a socket that makes Windows Firewall prompt or create a rule. ARFC 0017 clause 3.17 reserves no Windows Firewall rule, and Alloy makes none.

## Problem

On the third rung 2 hardware run (preview.5), the Windows client snapshot taken while joined had a new rule:
`Name=TCP Query User{FA88D8A0-...}C:\program files\alloy\alloy.exe; DisplayName=alloy; Direction=Inbound; Action=Block; EdgeTraversalPolicy=Block`.
The rule stayed after the uninstall, so both snapshot checks failed. Windows makes such a rule when an interactive program listens or binds on a wildcard address. On that machine the run used `alloy init` (refused at its host check), `alloy join <token>` as a client, `alloy login <code>`, and `alloy node list --output json`, all elevated.

The only listening socket in `crates/alloy/src` is the port check in `setup/probe.rs` (`busy_ports`). It binds UDP on `0.0.0.0` and `[::]` to the mesh port, and listens on TCP for the API port when the kind serves the API. Find which call made the rule. A TCP rule from a client join is unexpected, so check before you assume.

## Scope

- Find the socket that made the rule and say how you showed it.
- Change the check so it still detects a taken port, as ARFC 0002 requires, without making a firewall prompt. For example, on Windows read the system's TCP and UDP tables, or bind with `SO_EXCLUSIVEADDRUSE` without listening. If that needs a seam the `alloy-rt` `host` or `net` seam does not have, raise a `spec-change` issue and stop.
- A test that the Windows path never calls `listen` or a wildcard `bind_udp` through the `mem` `net`.

## Out of scope

- How `alloyd.exe`'s own mesh socket fares under Windows Firewall. That's rung 3.

## Acceptance

```
cargo test -p alloy    # expected: the new test passes
cargo xtask ci         # expected: exits 0
```

The report shows the trigger reproduced on this Windows machine before the change and gone after it. Remove any rule your own run creates (`Remove-NetFirewallRule`), and name it in the report.
