## Goal

Answer: do the released `CLOUDHV.fd` and `CLOUDHV_EFI.fd` images from the Cloud Hypervisor edk2 fork contain any GPL-licensed or proprietary component, and if so which, and can a build without them be produced from the fork's sources?

## Scope

- Identify the build configuration the fork's releases use (platform DSC/FDF files, build flags, CI workflow) and list every driver and library linked into each image.
- For each component that is not BSD-2-Clause-Patent or another license allowed by `agent/eng/deps.md`, give its license and whether it is in the shipped image.
- If anything disallowed is included, state the build flags or source changes that would leave it out, and whether the fork's CI already offers such a build.

## Out of scope

- Other firmware (Rust Hypervisor Firmware is already Apache-2.0 per R-0002).
- Building the firmware.
- Choosing what Alloy ships. That is an ADR after this note.
