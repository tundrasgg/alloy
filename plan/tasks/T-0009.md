## Goal

`alloy-sim` runs async Alloy code on a seeded, single-threaded executor with a virtual clock, network, and disk, and produces a trace hash.

## Scope

- The `mem` implementations of all five runtime seams.
- World building: hosts, links, routers.
- Fault injection for every fault in ARFC 0005 section 3.3.
- Event trace and trace hash.
- The 100-host echo scenario as an example.

## Out of scope

- NAT devices (T-0011).
- Checkers beyond trace hashing (a later task).

## Acceptance

```
cargo xtask ci                                           # expected: exits 0
cargo run -p alloy-sim --example echo -- --seed 1         # expected: prints a trace hash
cargo run -p alloy-sim --example echo -- --seed 1         # expected: the same hash
```

## Notes

If R-0001 led ADR 0036 to build on an existing runtime, this task wraps it. Otherwise it implements the executor. Split and report `blocked` if the executor alone exceeds the task size.
