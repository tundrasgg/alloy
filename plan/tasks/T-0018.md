## Goal

`cargo xtask check-commits <rev-range>` fails, with the commit id and the broken rule, on any commit in the range whose message breaks the "Commits on main" format in `agent/eng/git.md`.

## Scope

- A `check-commits` subcommand that takes a git revision range, walks its commits along the first parent, and validates each message.
- Rules to check: subject regex and 72-character limit; type from the table; scope present and from the allowed set (crate names under `crates/`, the listed top-level names, `ci`, `repo`); no trailing period; blank line after the subject; footers only `Task:`, `Spec:`, `BREAKING CHANGE:`, in that order; `Task:` ids match `T-NNNN`; `!` present exactly when `BREAKING CHANGE:` is; no other trailers such as `Co-Authored-By:` or `Signed-off-by:`.
- `Task:` is required unless the type is `chore` with scope `plan`.
- D-0016 path lock on main: for each commit in the range, if it changes a path locked in `agent/eng/testing.md` and no task named in its `Task:` footer is of type `verify` (read from `plan/tasks/` at that commit's parent), report a violation.
- Fixtures under `xtask/tests/fixtures/` with one passing and one failing message per rule.

## Out of scope

- Adding `check-commits` to `cargo xtask ci` or to the CI workflow. A task branch holds free-form commits, so wiring needs its own decision; file it as a `follow-up` in the report with a proposed range.
- Commit hooks.
- Rewriting existing commits on main.

## Acceptance

```
cargo test -p xtask                                # expected: passes, including one test per commit rule fixture
cargo xtask check-commits 40c70e9..main            # expected: exits 0
cargo xtask ci                                     # expected: exits 0
```

## Notes

Commit `40c70e9` is the bootstrap commit on main and predates the format; ranges start after it. Commit `2102651` on main uses `docs(adr)`, written before `agent/eng/git.md` assigned ADRs to type `spec`. If the second acceptance command fails only on that commit, the range for acceptance becomes `2102651..main`, and the report says so.
