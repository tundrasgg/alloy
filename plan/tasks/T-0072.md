## Goal

## Scope

- Start your branch from `task/T-0051`, not from main: merge `task/T-0051` into `task/T-0072`, then merge main, before any edit. Its workflow step is already written.
- Change the fallback start commit from `78d3175` to `26eef5f` (D-0027), and the comment that names it.
- Keep everything else T-0051 did: push events only, the before..after range, enough history fetched.

## Out of scope

- Commit hooks, pull request checks.
