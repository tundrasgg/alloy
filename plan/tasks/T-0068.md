## Goal

No source form outside `alloy-rt` and `alloy-sim` switches the direct I/O ban off, every OS call in the banned categories matches a configured path, and nothing the gate builds is outside the dependency allowlist.

## Scope

- F1 (`plan/reports/T-0046.reviewer.1.md`): reject every form the review shows switching the ban off (`warn(warnings)` with a ban lint, `allow` built by `macro_rules!`, and the others it lists), outside the two crates.
- F2: add the clock, thread, network, and file system paths the review lists, including those the old whole-module patterns covered (`std::thread::sleep_ms`, `park_timeout_ms`, Windows named pipes, and the rest), each with a fixture line.
- F3: the Clippy fixture's third-party packages either go through the same `cargo deny` license and advisory check as the workspace, with each added to the allowlist and reported, or the fixture is replaced by local stand-in crates with the same paths so it builds nothing from outside.
- Note F4: a test attribute on a line does not make unrelated code on that line test code.
