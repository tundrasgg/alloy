## Goal

`tests/conformance/log-store` and `tests/conformance/state-store` hold the suites ARFC 0006 section 5.5 names, written from the spec, so any implementation of the two seams can be checked.

## Scope

- Read only ARFC 0006 section 5 and ARFC 0001's seam rules.
- A case for every "must" of sections 5.3 and 5.4, each named by its clause, as functions that take an instance of the seam. The harness that runs them against `native` and `mem` comes when T-0107 merges. Until then, make the suites compile against the trait signatures of section 5.1, through a local stand-in that is only a type-checking aid and is never used as a passing implementation.
- Cases a real implementation cannot trigger deterministically are listed with a one-line reason.

## Out of scope

- Any change to `crates/`.

## Acceptance

```
cargo test -p conformance-log-store -p conformance-state-store --locked   # expected: compiles; cases that need an implementation are wired once T-0107 merges
cargo xtask ci                                                           # expected: exits 0
```
