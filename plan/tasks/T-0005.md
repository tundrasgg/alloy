## Goal

Answer: which NAT and firewall behaviors must the lab model, as which named presets, and what path class should each pairing reach?

## Scope

- Summarize the behavior axes of RFC 4787 and the discovery tests of RFC 5780.
- Propose 8 to 12 named presets covering home routers, carrier grade NAT, cloud provider NAT, mobile networks, strict enterprise firewalls, IPv6-only with stateful firewall, and UDP-blocked networks, each as values on the axes in ARFC 0005 section 3.4, with a source for the behavior.
- Give the expected path class for every ordered pair of presets under ARFC 0004 version 1 rules, as a table.
- Report any published measurements of how common each behavior is.
- Describe how existing open source NAT test harnesses model these devices.

## Out of scope

- Port prediction techniques beyond one paragraph.
- Implementing models.
