## Goal

ARFC 0003 sections 3.1 and 3.3 can be implemented with a standard Noise library without reaching into its internals, and leave no byte-level choice open.

## Scope

- Section 3.3 derives session keys from the "final chaining key", which Noise `Split()` and the `snow` crate do not expose. Respecify the derivation in terms the Noise specification exposes (for example `Split()` outputs, or the handshake hash), and keep the security properties the section states.
- Section 3.1: state the byte order of the counter `n` inside the 24-byte nonce.
- State the pre-shared key position (`psk0`, `psk1`, `psk2`, or none) if the handshake uses one.
- Write ADR 0043 if the derivation changes, and index it.

## Out of scope

- Choosing a crate. `alloy-crypto` picks one in its own task.
- The `rustls` crypto provider.
- Other sections of ARFC 0003.

## Acceptance

