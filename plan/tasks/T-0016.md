## Goal

Every push to `main` and every pull request runs `cargo xtask ci` on a GitHub-hosted runner, and the job fails exactly when the gate fails.

## Scope

- One workflow, `.github/workflows/ci.yml`, triggered on `push` to `main` and on `pull_request`.
- One job on `runs-on: ubuntu-24.04` that checks out the repository, installs the toolchain pinned in `rust-toolchain.toml`, installs `cargo-deny`, caches Cargo state, and runs `cargo xtask ci`.
- Top-level `permissions: contents: read`. Use `pull_request`, never `pull_request_target`.
- Pin every third-party action to a full commit SHA, with the version in a trailing comment.
- `concurrency` that cancels superseded runs on the same pull request.

## Out of scope

- Release, publish, or deploy workflows.
- arm64 or other operating system jobs.
- Any check that is not inside `cargo xtask ci`. New checks go into xtask, not the workflow.

## Acceptance

```
actionlint .github/workflows/ci.yml        # expected: exits 0, no output
grep -c "pull_request_target" .github/workflows/ci.yml   # expected: 0
grep "runs-on" .github/workflows/ci.yml    # expected: ubuntu-24.04
cargo xtask ci                             # expected: exits 0
```

The lead confirms the first run on GitHub after merge; the report need not.

## Notes

GitHub-hosted runners are used, not third-party or self-hosted runners (ADR 0037). Install a pinned cargo-deny, for example `cargo install --locked cargo-deny@0.20.2` (the version T-0001 verified), or a pinned prebuilt binary. If `actionlint` is not installed, install it with `go install github.com/rhysd/actionlint/cmd/actionlint@latest` or a release binary, and say which in the report.
