## Goal

On Linux, a read on a direct `disk-io` handle that crosses the end of the file returns every byte before the end, as ARFC 0005 clause 3.1.11 requires and as it already does on Windows. With that, `task/T-0083` can merge.

## Scope

- Start from `task/T-0083`, not main: check out a new branch `task/T-0095` from `task/T-0083`, then merge main into it.
- Make `os::disk::tests::a_direct_read_across_the_end_returns_the_bytes_before_it` pass on Linux without weakening it, and make the read loop correct for `O_DIRECT` on Linux: a short read is not end of file until a read returns 0 or the file length is reached.
- The lead runs the Linux acceptance. If your workspace is not Linux, say so and reason from the evidence below.
- Fold the T-0083 re-review note (F1, Windows 8.3 short names alias long names) only if it is small; otherwise leave it on the board.

## Out of scope

- Anything else in `alloy-rt`.
