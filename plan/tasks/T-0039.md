## Goal

Neither a compromised peer nor an underlay attacker can use the path manager to direct traffic at a third party beyond a stated bound.

## Scope

- Section 3.4 starts a probe set at once whenever either side's candidates change, with no rate bound. A compromised node that keeps changing its advertised candidates can make peers send probe rounds to a third party repeatedly. State a rate bound and what happens beyond it.
- Section 3.4, last bullet: an authenticated packet from a new source moves the return path at once. An underlay attacker that drops a fresh transport packet and reinjects it with a spoofed source can redirect data to a third party. Require verification of the new source before data moves to it, or bound what is sent there before it is verified.
- Section 8 states both bounds.
- Write ADR 0047 if either is a new decision, and index it.

## Out of scope

- Probe message bytes and probe replay (T-0038).
