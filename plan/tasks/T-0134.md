## Goal

`tests/e2e/rung2.ps1` follows the rung 2 profile of ARFC 0002 section 3.15:
1. `init` on the first Linux node.
2. `join` on the other Linux node and the Windows client.
3. A login code per machine, from `alloy login --issue-code` as root on the control node.
4. `alloy login <code>` on each machine.
5. `alloy node list` on each machine, showing all three nodes `healthy`.
6. An uninstall with `--purge --force` that leaves every machine as its snapshot.
