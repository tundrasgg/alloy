## Goal

`alloy init` and `alloy join` can enable and start `alloyd` and read the machine facts that ARFC 0002 section 3.8 checks, through `alloy-rt` (D-0072). That unblocks T-0141.

## Scope

- Read only ARFC 0005 sections 2 and 3.1, ARFC 0002 sections 3.1, 3.3, and 3.8, ARFC 0017 clause 3.17, the install scripts under `packaging/`, and the T-0141 report's Question.
- A `host` seam in ARFC 0005 section 2.3, with `os` rules for Linux (systemd) and Windows (the service control manager), and `mem`. It covers:
  - enable, start, stop, disable, and status of the reserved service `alloyd` only, and nothing else (ARFC 0017 clause 3.17);
  - the facts: privilege (root or elevated), OS and kernel or Windows build, architecture, cores, memory, virtualization support, disks, and free space at a path.
- How the seam relates to what the install scripts already do to the unit, so `init` and `join` never fight the installer.
- Each operation with a conformance test clause. State which `os` tests need privilege and where they run.
- ADR 0071 records the seam.

## Out of scope

- Building it (T-0141 round 2).
