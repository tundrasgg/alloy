## Goal

A conformance suite, generic over each runtime trait, that any implementation of `Clock`, `Net`, `DiskIo`, `Rng`, and `Spawn` must pass.

## Scope

- One test per 'must' in the cited sections and per documented behavior of each trait method.
- Hostile cases for `Net` and `DiskIo`: short reads, errors, cancellation mid-operation.
- The clause to test mapping table in the report.

## Out of scope

- Simulator-specific determinism tests (T-0010).
- Reading any implementation.

## Acceptance

```
cargo test -p conformance-rt --no-run   # expected: compiles
```
