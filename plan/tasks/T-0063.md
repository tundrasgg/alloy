## Goal

The per-packet overhead of an AL transport packet drops from 36 to 25 bytes (53 bytes with UDP over IPv4, 73 over IPv6), as the pilot directed (D-0024), with no weaker cryptography and no repeated nonce.

## Scope

- Fold `type` and `version` into one byte. Version 1 is fixed by the handshake; reserve the remaining values.
- Remove the `queue` field: each sending queue gets its own receiver index, so the index alone selects session, queue, and key state. State how indexes are allocated per session and the bound on indexes per peer.
- Send the low 32 bits of the counter; the receiver reconstructs the full 64-bit counter from its replay window, as QUIC packet numbers do. The nonce stays `salt || queue || full counter` or an equivalent that is unique per key. State the reconstruction rule, the reorder limit it implies, and that rekeying (section 3.3) keeps every session well below 2^32 packets.
- Remove the inner `kind` byte: IPv4 and IPv6 are recognized by the first nibble of the inner packet; keepalive, control, and fragment use first-nibble values no IP packet has. Define each.
- Remove the inner 3-byte `vni`: each receiver index is bound to one VNI, so a session carrying several VPCs uses one index per VPC (and per queue). State the bound.
- Update the overhead constant, fragmentation (section 3.5), and any section that reads the removed fields, including probes (section 3.6) if they share the header.
- Settle T-0054's open details in the new layout: fragment index origin, which inner kinds a fragment may carry, the fragment `reserved` byte, and queue id range (`plan/reports/T-0054.developer.1.md`, spec-issue).
- Record the change and its trade-offs in ADR 0058.

## Out of scope

- Shorter tags, a 2-byte counter, receiver index carried in addresses or ports, and a raw IP underlay. The pilot chose only the cuts above.
- Handshake messages (types 1 to 3).
