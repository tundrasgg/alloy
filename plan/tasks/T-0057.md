## Goal

A seam binding whose configuration was stored at an older version stays readable after any number of upgrades.

## Scope

- Finding F1 in `plan/reports/T-0006.reviewer.2.md`: clause 3.13 bounds the read window only by what the previous release writes, and nothing rewrites a stored binding at finalization, so a binding written at version `p - 1` and never changed becomes unreadable two releases later. Specify the rule that prevents it: for example, finalization (ARFC 0017 clause 3.3) rewrites every stored binding at the current version, or each release reads every version it may find in storage, and state the bound.
- ADR 0056 if this is a new decision.

## Out of scope

- Other clauses of ARFC 0001.
