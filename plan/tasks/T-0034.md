## Goal

Answer: do the current and previous major versions of Chromium, Firefox, and Safari accept a TLS server certificate chain signed with Ed25519, and if not, what key types must the API CA and the API server certificate use for the console to load?

## Scope

- For each browser and version, whether it accepts an Ed25519 server certificate, an Ed25519-signed chain, and Ed25519 in TLS 1.3 `signature_algorithms`, with a source (release notes, source code, bug tracker, or a reproducible test).
- The same for the CLI side: whether `rustls` with its default providers verifies Ed25519 chains.
- Options if browsers do not: for example a separate ECDSA P-256 API CA, or ECDSA only for the TLS certificate, with what each means for ARFC 0002 section 2.

## Out of scope

- Choosing an option. That is a spec task after this note.
