## Goal

CI runs `cargo xtask ci` with `--base` (and `--branch` where the checkout is detached), so the path lock in `check-repo` runs on every pull request and push.

## Scope

- In `.github/workflows/ci.yml`, pass the base ref for pull requests and the previous commit for pushes to `main`, with the branch name where `actions/checkout` leaves a detached HEAD.
- Fetch enough history for the base ref to resolve.

## Out of scope

- Any check outside `cargo xtask ci`.

## Acceptance

```
actionlint .github/workflows/ci.yml   # expected: exits 0 (official rhysd/actionlint; if it cannot run, report it and the lead runs it)
cargo xtask ci --base main            # expected: exits 0
```
