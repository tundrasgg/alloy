## Goal

ARFC 0004 and ARFC 0005 answer the four questions R-0003 found them silent or inconsistent on, so the NAT models (T-0011) and the NAT matrix (T-0012) can be built from the specs alone.

## Scope

- ARFC 0004 sections 3.2 to 3.4: say what happens between an endpoint-independent side and an endpoint-dependent side, in particular whether a probe is answered at the source address and port it arrived from. The expected path class for those pairs in R-0003's matrix follows from the answer.
- ARFC 0005 section 3.4: reconcile the mapping-timeout axis range (30 to 300 s) with the published values in R-0003 (10 s to 350 s). Widen the range or state that values clamp.
- ARFC 0004 section 3.4 against ARFC 0005 section 3.4: the 25 s keepalive leaves a 5 s margin over the 30 s axis floor. Decide whether a preset below the keepalive interval exists to exercise the failure path, and what the spec expects then.
- ARFC 0004 sections 3.2 and 3.6: a `udp-blocked` node waits 3 s for UDP before using the `stream` underlay, which conflicts with relay reachability within 2 s of joining. Change one number or give `udp-blocked` its own bound.
- Write ADR 0039 if any of these changes behavior, and index it. Clarifications need no ADR.

## Out of scope

- Real-mode NAT scripts (ARFC 0005 section 3.5).
- Other sections of ARFC 0004 or ARFC 0005, including the open question T-0006 closes.
