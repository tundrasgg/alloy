## Decisions

- Class N: a manifest found under `<chain dir>.alloy-old`, with `<chain dir>` missing, that lists `dir <chain dir>` is read as the install's manifest in state `pending`. The next uninstall (step 7) or install (step 6) moves the directory back before anything else. Steps 1 to 5 still change nothing. A manifest there that does not list the directory exits 1, since it cannot be shown to be Alloy's.
- Class R: after an uninstall that leaves `/usr/local/share/alloy` holding another file, an install exits 5 naming that directory, as clause 3.15 step 4 says for an existing path with no manifest.
- Class R: during an upgrade, a `dir` of the earlier install that holds other files stays listed in the new manifest, as in round 1, so that a later uninstall removes it once it is empty.

## Issues

- `spec-issue`: the F1 behavior needs text in `spec/arfc-0017-upgrades-and-versioning.md` clause 3.16 step 7. A directory that is not empty is left in place, and the uninstall says so, removes the manifest, and exits 0. A rerun does not try that directory again.
- `spec-issue`: the F2 behavior extends the round 1 `spec-issue` on markers for clause 3.15 steps 4 and 6 and clause 3.16 step 2. An uninstall moves a directory to `.alloy-old` only when it is a marker in place. A manifest under `<dir>.alloy-old` that is not in a marker, with `<dir>` missing, is the manifest, and the next run moves it back.
- `follow-up`: review finding F3 (note) is not changed in this round. On Linux and macOS, extracting as root into a root-owned directory needs a root-only parent, which `${TMPDIR:-/tmp}` does not guarantee. On Windows the elevated `%TEMP%` is writable by the same user's non-elevated processes. The fix is to copy the checked archive into a directory only root or Administrators can write, then check, extract, and copy from there. It belongs in the next task on `packaging/`.
- `follow-up`: the round 1 follow-ups still hold. The Windows install and uninstall have not run elevated on this host, and `check-removal.ps1` exercises only the removal functions. The full Windows uninstall with other files in `%ProgramFiles%\Alloy` is first run by the rung 1 check (T-0093).
- `process-issue`: `sh packaging/check.sh` on Git Bash for Windows still takes several minutes for its prefix runs. It is meant for Linux, where it takes seconds.
