## Decisions

- Scope is taken from the first path in the task's `touches` list (crate name under `crates/`, `ci` for `.github/`, the top-level directory name otherwise, `repo` for root files). Reason: one answer per task with no judgment call.
- Added an eleventh type, `revert`, first in the table, because `agent/core/6-pace.md` allows reverts when main is broken. Types are matched in table order when several fit.
- `agent/` changes, so `process` tasks, use type `docs`; `plan/` changes use `chore`. Reason: `spec` is kept for normative ARFCs and ADRs.
- `Spec:` is present only when the task's `spec` field is non-empty, entries copied in order. `Task:` is always present on task squashes and optional on the lead's own `plan/` commits.
- Footers are limited to `Task:`, `Spec:`, and `BREAKING CHANGE:`. A breaking change uses `!` and the footer together and names its ADR, since such a change is pivotal under `agent/core/3-autonomy.md`.
