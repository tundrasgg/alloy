## Summary

`tests/conformance/wire/` (crate `conformance-wire`, test target `conformance_wire`) holds 73 tests for ARFC 0003 sections 3.1, 3.4 and 3.5. Each test is named after the clause it checks, and each was written from the ARFC and the public API of `alloy-wire` only.
Hand-built byte vectors cover types 1 to 4, both handshake payloads, every inner frame kind and the fragment frame. Each vector is decoded, checked field by field, and re-encoded. Every fixed value, drop rule and bound in the cited sections that a byte codec can judge has a rejection test.
The library holds the table layouts and a model of the rules, written a second time from the ARFC. Seven seeded properties compare the decoders with that model on mutated inputs, and each property must see each decision go both ways at least 64 times.
The suite passes against `alloy-wire` on main, and `cargo xtask ci` exits 0. No vector disagrees with the implementation. Musts that need session or reassembly state are listed below as out of the codec's scope.

The suite separates right from wrong. One hand vector first failed: `(w = 0, H = 0x7fff_ffff)` was expected to give `0`. The ARFC gives e = 2^31 and the interval (0, 2^32], so 0 is excluded and the answer is 2^32. That is what the codec returned:

```
assertion `left == right` failed: w = 0x0, H = Some(7fffffff)
  left: Some(4294967296)
 right: Some(0)
```

The error was in the vector, not in the codec. The vector was corrected from the ARFC arithmetic, not from the codec's output, and the boundary case is now kept as its own row. Proving that every test fails before the code existed is not practical: per D-0022 the codec was merged first.

## Decisions

- N: the suite is a workspace member crate, `conformance-wire`, because `cargo test --test conformance_wire` needs a member with that test target. I added it to `Cargo.toml` `members` and to `deny.toml` `[bans] allow`, which are shared workspace files outside the task's `touches`. This follows the precedent of `tests/conformance/sim` on `task/T-0010`.
- R: rejections assert the `DecodeError` variant that `alloy-wire`'s public docs give for each cause, not just `is_err()`, so that drop counts by cause stay right. The models compare only keep or drop.
