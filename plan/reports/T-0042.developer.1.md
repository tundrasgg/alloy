## Decisions

- The path lock reads the task file at the tip of `--base`, not at the merge base: task files are committed to main before dispatch and are immutable after it, so both give the same file, and the tip needs no extra git call.
- A task branch whose task file is absent on the base ref, or has no `type` there, fails the path lock, as an absent task file did before.
- Fixture cases may hold `base/` (files as on the base ref) and `files` (a list created at test time) besides `repo/`; documented in the `fixture_tests` module doc.
