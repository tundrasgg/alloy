## Summary

Round 3 closes the gate failure of D-0057. After main (T-0106) was merged, the tree holds `sha2` 0.10.9, through `quorum-set` 0.6.2 under `openraft` 0.10.0, and `sha2` 0.11.1, through `alloy-crypto`, so `cargo deny` refused the duplicate.
No release removes it: `quorum-set` 0.6.2 is the latest, and it depends on `sha2` 0.10 unconditionally. `openraft` 0.10.0 is the latest too, and `alloy-crypto`'s tree (`ed25519-dalek` 3, `p256` 0.14) needs 0.11. So `deny.toml` now skips `sha2@0.10.9` by exact version, beside the four crates under it that round 1 already skipped.
No product code changed in this round. Main was merged into `task/T-0107` again (spec and plan changes only).
