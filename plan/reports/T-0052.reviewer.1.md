Attacks tried. This is a spec task with no code, so each attack is a scenario traced through the amended clauses. Setting: PB-0001, user `admin` in org `default` is the only `cloud-admin` and `owner` of `default`, and a thief holds its only key K.

1. **T-0044 F1, hidden last `cloud-admin`.** The thief gives U2 in org X `cloud-admin` and removes it from `admin`. The local admin lists every org and user with roles (3.10.7 "see"), or ignores U2, revokes K (3.9.13), and restores `admin` or creates a fresh user and grants it `cloud-admin` ("restore"). No step needs a name the thief chose. Resolved.
2. **T-0044 F2, deny on the recovered user's org.** The thief attaches a deny `*` on `*` to `default`. `iam:*` with no deny binding the local admin lets it detach it ("unbind"), and 3.10.7 bullet 3 then requires the recovered key to be allowed. Resolved for O. The same deny attached to a different org P than the recovered user's org is not covered by the procedure or by the bullet's exceptions (F1).
3. **Recovery blocked by a limit.** The thief fills login code room: 10 unused codes per user evict only the user's own oldest, and churning the 10,000 kept codes per cluster needs exchanges at 100 per second with K. Revoking K first (cutting off precedes, 3.10.7) stops it. Key limits fall to 0 after 3.9.13. No limit found that the thief can hold against the procedure.
4. **Tenant data through the local admin.** `iam:*` on every org covers `iam:IssueLoginCode` for any enabled user, and 3.10.2 only stops the exchange on the socket, not over the API. Root issues a code for an `owner` of org P, exchanges it over TCP, and reads P's data as that owner. No grant is made. Each step is in P's chain (3.9.9, 3.10.6), and the write raises the warning (3.10.8). The conclusion of the I-02 argument holds, the stated reason does not (F2).
5. **Compromised compute node.** A local admin call, read or write, arriving over an AL session whose node record lacks `control` is refused under 3.10.4, now for forwarded reads too. ARFC 0020 section 3.3 holds.
6. **Warning suppression.** A stolen `cloud-admin` key, and root itself, cannot delete or shorten the record (3.10.8). Reads and denied calls do not touch it. The state is one record (I-21). Holds.
7. **Socket methods.** 3.10.2 serves every native API method except `ExchangeLoginCode`. ARFC 0002 section 3.7 says it is the only method not authenticated by a principal, so no other method needs excluding. Holds.
