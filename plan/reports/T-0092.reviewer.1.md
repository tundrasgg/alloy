Attack 1, interruption (clause 3.15 "An install interrupted at any point ...", clause 3.16, section 6). Shims for `mv`, `cp`, `mkdir`, `chmod`, `rm`, and `rmdir` count calls and `kill -KILL 0` the script's process group (started with `setsid`) before call k, for k = 1 to the end. Each interrupted run is followed by a rerun and then `install.sh --uninstall`, or by `install.sh --uninstall` alone. The file tree under `/usr/local`, `/etc/systemd/system`, `/var/lib/alloyd`, and `/run/alloy`, with SHA-256 prefixes, must then equal the tree before the install:
