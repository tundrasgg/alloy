## Decisions

- N: SigV4's SHA-256 and HMAC are in `alloy-crypto`, outside `touches`, since crypto rule 1 puts every primitive there (round 1 change, kept).
- N: an exchange of a used, voided, or expired code fails `PermissionDenied`, with the reason (`login_code_used` and so on) leading the message. No spec gives the code.
- N: `ControlNode::stop` takes the group from the API before it shuts down, so a connection left open gets `Unavailable` and holds no store.
- R: the `alloyd` tests run under `os` on loopback with a `disk-io` that gives `Protection::Default`, because a non-administrator on Windows may not name `Administrators` as owner.
