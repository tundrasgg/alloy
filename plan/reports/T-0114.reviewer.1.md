## Issues

- spec-issue: ARFC 0002 section 3.13 (`spec/arfc-0002-identity-and-join.md:922`) allows "any pre-release suffix" for `JoinHello.release`, and ARFC 0006 section 4.3 answers `INVALID` to a heartbeat whose `release` is not spelled that way. Neither defines the suffix grammar. The branch applies strict SemVer 2.0.0, so a join path that accepts more (for example `1.2.3-01`) would see that node's heartbeats refused as `INVALID`. Section 4.3 or ARFC 0017 should fix the grammar.
