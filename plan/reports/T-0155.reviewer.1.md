F2. `/proc/<pid>/comm` is the task name as written, unescaped (Linux master):

```
$ curl -s https://raw.githubusercontent.com/torvalds/linux/master/fs/proc/base.c | grep -n -A11 "static int comm_show"
1740:	proc_task_name(m, p, false);
fs/proc/array.c proc_task_name: if (escape) seq_escape_str(...); else seq_printf(m, "%.64s", tcomm);
```

Any unprivileged process can set its own name with `prctl(PR_SET_NAME)`
(<https://man7.org/linux/man-pages/man2/pr_set_name.2const.html>), ESC, CR, and LF included, and
hold UDP 7476. Under the new text, `alloy init` run as root prints those bytes unchanged.

F4. Windows reserves port ranges that have no socket behind them. On the review machine:

```
$ netsh interface ipv4 show excludedportrange protocol=tcp

$ netsh int ipv4 show dynamicport udp
Start Port : 49152   Number of Ports : 16384
```

A bind into such a range fails, but `GetExtendedTcpTable`/`GetExtendedUdpTable` list no row for it.
Today's `busy_ports` (`crates/alloy/src/setup/probe.rs:281-315`) reports any bind error other
than `AddrInUse` as "not available" and fails the check. The new check passes such a port.
