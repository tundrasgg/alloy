## Summary

`host-snapshot.sh` now removes every `ip -d link show` value the kernel changes
during normal operation, `fdb_n_learned` and every bridge timer included, keeping
the attribute names and all configuration. It also removes named nft counter
values. It has a `--self-check <seconds>` mode that diffs two snapshots. The
README lists each value removed and why, and documents the self-check for Linux
and Windows.

| Clause | Check |
|---|---|
| arfc-0017#3.17.6 counters, statistics, timestamps removed | `host-snapshot.sh --self-check <seconds>` (the lead runs it on both Linux nodes) |

## Changes

- `tests/e2e/host-snapshot.sh`: `norm_link` removes the values of `promiscuity`, `allmulti`, every `*_timer` (the name may now contain digits, so `mcast_querier_ipv4_other_timer` matches), `fdb_n_learned`, `mcast_n_groups`, `mcast_querier_ipv[46]_addr`/`_port`, `topology_change`, `topology_change_detected`, `topology_change_ack`, `config_pending`, `link_failure_count`, and CAN `berr-counter`. `norm_nft` also removes the `packets N bytes N` line of named counter objects. New `--self-check <seconds>` mode prints PASS/FAIL, `-`/`+` differences per section, and SUMMARY, and exits 0/1/2.
- `tests/e2e/README.md`: one table row per value removed, with its reason. A paragraph on what is kept and the audit of the other commands. A section "Checking that snapshots are stable" with the Linux self-check commands and a Windows PowerShell command.

## Decisions

- The value is removed and the attribute name kept, for `promiscuity` and `allmulti` too, so an attribute that appears or disappears still shows.
- STP results (`designated_root`, `root_port`, `root_path_cost`), bond `ad_info`, and tap `numqueues` are kept: they hold still on an idle machine.
- The self-check pipes both snapshots into one `awk`, so it still writes no file. It compares lines as a multiset per section, as `Get-LineDiff` in `rung1.ps1` does.
