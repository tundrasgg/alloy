## Decisions

- N: `proptest` is declared without default features, with `std` only. The defaults add `fork` and `timeout`, which run each test in a child process under a wall clock timeout, and `agent/eng/testing.md` bars wall clock reads in tests. A crate that needs another feature adds it at its use site and extends the allowlist.
- N: versions are exact (`=`) pins, as the task says "pinned". Transitive versions are pinned by `Cargo.lock` once a member uses the crates.
- R: allowlist entries name crates without versions, the same as the existing entries. `multiple-versions = "deny"` already refuses a second version.
- R: the allowlist covers all targets (`deny.toml` sets no `[graph] targets`), so it includes `r-efi` and `libc`, which only some targets build.
