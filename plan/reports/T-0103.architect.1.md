## Decisions

- Rung 2 runs two groups (global, regional `default`) on one voter, not one merged group, because ARFC 0001 clause 3.13 and ARFC 0006 section 2.2 assume separate groups.
- "Healthy" in the rung 2 check means state `active`. Deleting a node is its revocation, and a deleted node leaves the list, so there is no `revoked` state (ARFC 0002 is outside this task's `touches`).
- A heartbeat is the API call `ReportNode`, authenticated by the node identity key. It goes over the underlay to a control node's advertise addresses, or over the mesh to its infrastructure address once an AL session exists (rung 3). The interval is 5 s, so a node misses 6 before the 30 s rule makes it `unreachable`.
- Store bindings are node-local, and `mem` contents outlive instances by `name`, so tests can model restarts. `fail_after` is a fault hook for the poison rule.
- Each group keeps its own audit chains, since records commit with their change (ADR 0064, Consequences).
- The ZONE column appears only with more than one zone, so the default columns fit T20 in 100 columns.
