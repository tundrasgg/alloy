## Issues

- `spec-issue`: `rt_path` on Windows can never succeed when the configured root is a verbatim (`\\?\C:\...`) or UNC path. `resolve_root` accepts any absolute path (`crates/alloy-rt/src/os/config.rs:236`), but clause 3.1.15 requires `native` to start with a drive letter and to match every component of `root`. ARFC 0005 section 4.2 should restrict `root` on Windows to a drive path, or clause 3.1.15 should say how such a root is matched (`spec/arfc-0005-simulator-and-natlab.md`).
