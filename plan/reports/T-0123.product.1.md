## Decisions

- Install commands use the pinned `releases/download/<tag>/` URL, not ADR 0044's `releases/latest/download/`: GitHub's latest release skips pre-releases, so the latest URL does not reach a preview.
- The README does not list which commands a preview runs, since that changes with each rung; it says a preview carries only part of the design and points to `plan/STATE.md`.
