## Decisions

- N: the fuzz graph has its own `fuzz/deny.toml` instead of sharing the root one. One shared file cannot hold an exception and allow entries for one graph only. cargo-deny has no per-graph sections, and `bans.deny` wrappers would still leave the license exception and `arbitrary` and `jobserver` allowed in the root graph. The cost is that the license list, advisories and sources settings now appear in two files, and both files say to keep them in step.
- R: round 2's `unused-license-exception = "allow"` is gone. The exception now lives only in the file of the graph that uses it, so cargo-deny's default warning would report it if it ever went stale.

## Issues

- `spec-issue`: `agent/eng/deps.md` ("`deny.toml` at the repository root is the allowlist") and ADR 0060 ("`deny.toml` admits NCSA through one license exception") name only the root file. They should also name `fuzz/deny.toml` as the allowlist of the fuzz graph, and say the exception lives there.
