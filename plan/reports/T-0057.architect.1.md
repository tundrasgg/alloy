## Summary

Resolved finding F1 of `plan/reports/T-0006.reviewer.2.md` in ARFC 0001 clause 3.13: finalizing the upgrade to release `R` switches writers to `V(R)` and rewrites every stored binding at another version to `V(R)`, and completes only when none remains.
The upgrade to `R + 1` must not start before that, and `MIN_VERSION` of `R + 1` is bounded by `V(R)`, so every release decodes at most its predecessor's `VERSION` to its own.
`to_value(VERSION)` must never return `NotExpressible`, so the rewrite cannot lose a value, and a rewrite is not a binding change (no swap, drain, or restart).
This is a behavior change, recorded in ADR 0056. It needs one review before merge.

## Decisions

- Chose rewrite at finalization over "each release reads every version ever stored", because the latter never lets `MIN_VERSION` rise (ADR 0056).
- A binding finalization cannot rewrite (implementation absent from the release, or `from_value` fails) blocks finalization with a report naming the resource, rather than being skipped, because a skipped binding is exactly the one that later becomes unreadable.
- Binding identity is by name and decoded configuration, not bytes, so a rewrite never triggers swaps or drains across the cluster.

## Issues

- `spec-issue`: `spec/arfc-0017-upgrades-and-versioning.md` clause 3.7 and section 7 do not state that an upgrade to `R + 1` (and `alloyd` of `R + 1`) refuses while the upgrade to `R` is not finalized; ARFC 0001 clause 3.13 now requires it, and ARFC 0017 should carry it, plus the binding rewrite as part of `--finalize`.
- `follow-up`: `spec/arfc-0017-upgrades-and-versioning.md` clause 3.10 names no conformance suite for the upgrade scenarios that ARFC 0001 section 5 now points to for the stored binding rules.
- `follow-up`: `spec/arfc-0006-control-plane.md` clause 3.10 keeps state backups for 7 days; restoring a backup taken before a finalization into a later release can bring back bindings older than that release's `MIN_VERSION`. No ARFC states how a restore handles versioned state across releases.
