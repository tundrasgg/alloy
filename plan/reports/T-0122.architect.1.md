## Summary

ADR 0067 supersedes ADR 0008. It keeps the `alloy-rt` and lint rule unchanged,
moves the simulator off "before any feature", says what runs on `alloy-sim` until
M11 exits, binds crates built before the simulator to no direct I/O and
determinism for a given input sequence, and names three gates: consensus and mesh
path tasks after M11, every milestone exit but M11, and any stable release.

## Decisions

- Mesh path means handshake, rekey, path selection, relay, and NAT traversal (ARFCs 0003, 0004); consensus means consensus or replication (ARFC 0006). Gated after M11 only.
- Determinism is checkable now through the ARFC 0005 clause 3.2.5 trace hash wherever a crate's tests already run on `alloy-sim`.

## Issues

- `spec-issue`: `spec/arfc-0005-simulator-and-natlab.md` section 1 says the simulator "is built before anything else", and its header lists decision 0008; both contradict ADR 0067 and the ARFC outranks it. Needs a spec change (out of scope here).
- `process-issue`: `agent/eng/testing.md` Determinism says every test above the unit layer runs on `alloy-sim`; the M11 rung scripts under `tests/e2e/` do not. ADR 0067 records the exception; the rule's text should name it.
