## Decisions

- R: `unused-license-exception = "allow"` keeps root `cargo deny` output clean. One `deny.toml` serves both graphs, and the exception can only ever match in the fuzz graph. The cost is that a stale exception would go unreported. That is acceptable while the file holds exactly one exception, and ADR 0060 pins it.
- R: this round's commits were made on a detached HEAD at the tip of `task/T-0061`, then fast-forwarded onto the branch (see Issues).
