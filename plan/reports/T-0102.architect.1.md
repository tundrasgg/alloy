## Summary

Rung 2 identity, join, API transport, and ports are specified. A new node channel (ARFC 0002 section 3.13) defines the join messages, which had no bytes before. It also covers renewal, leave, and status: protobuf datagrams on VNI 0 of the AL session to an anchor, over the underlay. The mesh port is UDP 7476. The API is gRPC on tonic/prost over TLS 1.3 on TCP 443, which it shares with `stream` by ALPN, and SigV4 is bound to gRPC. TLS randomness is ruled in crypto.md rule 4 and ADR 0042. ADR 0063 supersedes ADR 0061 (T-0090.2 F1) and closes F2, and T-0088.2 F1 and F2 are closed in ARFC 0002 section 3.12.

## Decisions

- Join messages ride IPv6/UDP 7477 on VNI 0 inside AL, not new AL control types (ARFC 0003 not in touches) and not TLS. Why: `al0` carries the same bytes at rung 3, and the token pins mesh keys.
- Rung 2 traffic: only the node channel on home sessions over the underlay. Relay, signaling, paths between nodes, and `al0` wait for rung 3. The API never rides the mesh.
- The CLI reaches the API through `alloy login` on every machine. Join makes no context. Root on the control node issues the extra codes over the local admin socket.
- Mesh UDP 7476, API and `stream` TCP 443 shared by ALPN. Why: 7476 is IANA-unassigned and outside the ephemeral ranges, and `stream` exists to pass firewalls that allow only 443.
- The API is on tonic over prost (R-0007 option B). Why: it keeps the standing `prost` choice. connect-rust is pre-1.0 and uses `buffa`.
- The TLS randomness exception is limited to `os`, and the simulator runs no TLS. Why: `aws-lc-rs` generates key shares internally, and a custom provider is new crypto glue.
- `--data-dir` removed. Why: it closes T-0088.2 F2 with no new reserved record, and a mount moves the directory instead.
- ADR 0042 holds several related rulings, since only two ADR numbers were allocated and ADR 0040 sets the multi-part precedent.
