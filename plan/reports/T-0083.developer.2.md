## Changes

- `Cargo.lock`, `deny.toml`: merge of main. The lockfile adds the same 10 packages as round 1. `getrandom` and `libc` keep this branch's reasons, and every other shared entry takes main's.
- F1 (block), `crates/alloy-rt/src/os/mod.rs`: `HostInner` has a `timers: RwLock<bool>` gate. `SleepUntil::poll` holds it shared from its check until the `tokio` poll returns. `shutdown` closes it exclusively before it stops the runtime, so no poll can be between its check and `tokio` while the driver stops. The `tokio` sleep is now dropped before the host reference. Test: `sleeps_polled_while_the_host_shuts_down_never_panic` (500 rounds; four threads poll and drop sleeps before, during, and after `shutdown`).
- F2 (fix), `crates/alloy-rt/src/os/disk.rs`: on a direct handle, `read_one` stops once a platform read ends off a block boundary, because that is end of file. It returns `Ok(n)` with the bytes before the end. Test: `a_direct_read_across_the_end_returns_the_bytes_before_it` (reads at `block`, `[0, 2*block)` and `2*block` of a `block + 904` byte file).
- F3 (fix), `crates/alloy-rt/src/os/disk.rs`: a new `platform_create` gives an exclusive open no create flag, so Linux `O_EXCL` keeps its block device meaning ("fail while held"). Test: `an_exclusive_open_creates_nothing`.
- F4 (fix), `crates/alloy-rt/src/os/disk.rs`: `SYNC_READ_HANDLES` is gone, replaced by `platform::sync`. On Windows, a read handle is flushed through a write handle from `ReOpenFile` on the same open file, so a rename does not matter. If the platform refuses that handle, `sync` returns its error, never a silent `Ok`. `Cargo.toml` adds the `Win32_Storage` and `Win32_Storage_FileSystem` features to `windows-sys`. Test: `sync_on_a_read_handle_makes_the_file_durable` (both kinds, and again after a rename).
- F5 (fix), `crates/alloy-rt/src/os/net/udp.rs`: off Linux, `bind_udp` returns `NetError::Unsupported` when `quinn-udp` reports `may_fragment()`. It does the same for IPv4 on platforms where `quinn-udp` sets no IPv4 don't fragment option: every Unix platform other than Apple, FreeBSD, and Android (Linux has its own path). On Linux a refused `IP_MTU_DISCOVER` already failed the bind. It now returns `NetError` directly.
- F6 (fix), `crates/alloy-rt/src/os/net/mod.rs`: `interfaces(Some(g))` completes when the generation passes `min(g, first read's generation)`, which is the first change after the call even when `g` is ahead. The rule is the pure function `answers`. Test: `a_wait_ends_at_the_first_change_after_the_call`.
- F7 (note), `crates/alloy-rt/src/os/disk.rs`: on Windows, `native` returns `InvalidPath` for a component with a trailing dot or space, a character Windows forbids or reads as a stream separator (`<>:"|?*`, controls), or a reserved device name with or without an extension (`CON`, `PRN`, `AUX`, `NUL`, `CONIN$`, `CONOUT$`, `COM1`-`COM9`, `LPT1`-`LPT9`, and their superscript forms). Test: `plain_names_only_extend_the_root` now checks 18 aliases and 7 plain names on each platform.

## Decisions

- Class N: `windows-sys` gains the features `Win32_Storage` and `Win32_Storage_FileSystem` for `ReOpenFile`. No new crate and no lockfile change.
- Class N: a new `unsafe` block, `reopen_for_write` in the Windows `platform` module of `os/disk.rs` (`ReOpenFile`, then `OwnedHandle::from_raw_handle`), with `// SAFETY:` comments. `alloy-rt` may use `unsafe` (`agent/eng/rust.md`).
- Class N: on Unix platforms other than Linux, Android, Apple, and FreeBSD, IPv4 `bind_udp` now always returns `Unsupported`, because `quinn-udp` sets no don't fragment option there and I-10 forbids a silent fallback. None of these is a supported target (`agent/eng/rust.md`).
- Class N: on Windows, `os` disk paths reject the F7 names with `InvalidPath`. That is an `os`-only narrowing of the paths `RtPath` accepts, under the rule already stated in `native` (a component must name exactly itself).
- Class R: the shutdown gate is a `std::sync::RwLock<bool>` held only for the length of one `tokio` timer poll. Sockets need no gate: `tokio` returns an error, never a panic, for I/O after its driver stops.
