## Issues

- spec-issue: `spec/arfc-0003-mesh-wire-protocol.md` 3.3: "the previous session's receive key stays valid for 10 seconds after a rekey" names neither the event that starts the 10 seconds nor which session is previous when the two nodes order sessions differently; 3.6 resolves this for probe keys only and says a lost response leaves "both nodes on the previous session, which both still hold". F1 needs that sentence made exact for transport.
