## Summary

The exit 1 came from step 7: `foreach ($mk in Get-AlloyMarkers)`. A function that ends
with `return ,$out` hands back its array as one object, so a foreach over the call runs
once with `$mk = @()`, and `Remove-Item -LiteralPath @()` throws exactly the reported
message. Every such loop now goes over a variable. `packaging/check.sh` passes.
`cargo xtask ci` fails only at check-repo, on a line in this task's own file.

## Changes

- `packaging/install.ps1`: the shared block assigns `Get-AlloyHostMatches`, `Get-AlloyMarkers`, `Get-AlloyReserved` to variables before looping, with a comment on the convention. `Test-AlloyConflicts` does the same.
- `packaging/uninstall.ps1`: the shared block synced by `sync-shared.sh`.
- `packaging/check-removal.ps1`: on Windows, runs the whole `Invoke-AlloyUninstall` on a clean client install (as `Get-AlloyPlan` lays it out) under a temporary root. Elevation is stubbed, the service name is unique, and the path entry is absent from the machine path. Checks for no error, the directory and markers gone, and no unnamed "Left" line.
- `packaging/README.md`: the `check-removal.ps1` row names the new check.
