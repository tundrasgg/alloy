## Summary

Fix round for `plan/reports/T-0136.reviewer.1.md`. The fixes: F1 to F3 (`block`), F4 and F5 (`fix`), and F6 (`note`). Each has a test that drives it through `alloyd`'s library interfaces.
F1: a joined node without `control` is served as a member node. F2: a node with an expired record is held as an unregistered initiator and renews through the join service. F3: a record with no `Node` is completed or removed. F4: an expired `joining` node is deleted within 60 s of `not_after`, since its deletion is due at + 50 s. F5: `--roles compute` with no virtualization is a usage error.
The `join` and `init` signatures T-0141 calls are unchanged.

## Changes

- F1 `crates/alloyd/src/control.rs`: `read_stored` returns `NotControl` from the record's roles before it reads the cluster key.
- F1 `crates/alloyd/src/lib.rs`: `serve_joined(runtime, paths, listen, bind, transport)`, which `start_node` calls. It serves a control node, else a member node on `NotControl`. Also `Serving::stop`.
- F2, F3, F4 `crates/alloyd/src/nodes.rs`: mesh keys are admitted only while their record is valid. They are forgotten once it expires, at start, on each lifecycle tick, and on any request (`holds_valid`). A renewal makes the node a registered peer again. Each tick also completes a record with no `Node` (`ensure_node`) or removes it once its deletion is due. `joining` deletion is due at `not_after` + 50 s (`JOINING_DELETE_AFTER_SECS`), measured from the stored record.
- F2 `crates/alloyd/src/member.rs`: a node with a valid record renews over its home session, as before. With an expired record it opens a new session to each home in turn as an unregistered initiator. It sends `join_hello` and checks the reply as in step 5, within 10 s, then sends `renew` there. A home with another cluster key stops renewal, as `node_unknown` does. Homes are dialed again after a success.
- F2, F5 `crates/alloyd/src/join.rs`: `check_proof` takes the cluster id and fingerprint, and `wait_session` is `pub(crate)`. `check_options` returns `Usage` when `--roles` names `compute` and `facts.virtualization` is false.
- `crates/alloyd/src/tests/node.rs`: a `Shifted` wall clock over `os`. `start_member` goes through `serve_joined` (F1). The F2 test covers an expired node: its heartbeat on a new session gets no reply, and its renewal through the join service gives serial 2 and `active`. The F3 and F4 test covers the crash-point record, which is completed. An expired one is removed, and a `joining` node is gone by `not_after` + 60. The F5 test checks for a usage error with nothing written.
- F6 `plan/reports/T-0129.developer.1.md`, `plan/reports/T-0130.developer.1.md`: removed from the branch, as main has removed them.

## Decisions

- R: in rung 2 an expired node takes a renewed record only when the home's current cluster key is its own. Rotation is not built, so a proof that holds only a previous key fails for that address.
- R: `joining` deletion is due at `not_after` + 50 s. The other 10 s cover the 1 s tick and the deletion's writes.
- R: the lifecycle tick reads every node record each second. That is cheap at rung 2's sizes, and it is what keeps registration and orphan repair exact.
