## Decisions

- N: on Linux, a symbolic link at any directory above the data directory fails the rules, as a reparse point does on Windows. `disk-io` cannot read a link's target, and 3.12 already says to mount a disk at the path.
- N: `rt_path` is a synchronous `DiskIo` method. It returns `Unsupported` under `mem`, and writes no trace record.
- N: a `set_mode` becomes durable only through `sync(All)` on the file or `sync_dir` of the directory itself. A `sync_dir` of the parent does not count.
- R: under `os` on Linux, the mode is reset through a descriptor of the new entry, and on failure the entry is removed.
