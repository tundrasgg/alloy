# Research notes

One file per question, `R-NNNN.md`, written by the researcher role from
`agent/templates/research.md`. The lead allocates numbers from `plan/STATE.md`.

A note answers one question with sources and ends with options. It decides
nothing. Decisions that follow from a note cite it.

Notes are never edited after they merge. If the facts change, a new note
supersedes the old one and says so in its first line.
